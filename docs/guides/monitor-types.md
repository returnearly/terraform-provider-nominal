# Monitor types

`nominal_monitor.type` is one of: `Http`, `GraphQL`, `Ping`, `Tcp`, `Dns`, `Tls`, `Heartbeat`, `Udp`, `WebSocket`, `Mysql`, `Redis`, `Postgres`.

`target` is always required. Other fields are type-specific. Nominal ignores fields that do not apply to the type (for example `method` on a Ping monitor).

## Field matrix

| Type | `target` | `method` | `request_headers` | `request_body` | `verify_tls` | `proxy_url` | `dns_query_*` |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `Http` | URL | yes (default `GET`) | yes | HTTP body | yes | yes | — |
| `GraphQL` | URL | yes (default `POST`) | yes | GraphQL query | yes | yes | — |
| `Ping` | host | — | — | — | — | — | — |
| `Tcp` | `host:port` | — | — | payload | — | yes | — |
| `Udp` | `host:port` | — | — | payload | — | — | — |
| `Tls` | `host:port` | — | — | payload | yes | yes | — |
| `WebSocket` | `ws://` or `wss://` URL | — | yes | payload | yes | yes | — |
| `Dns` | resolver (for example `1.1.1.1`) | — | — | — | — | — | required name, type defaults to `A` |
| `Heartbeat` | job label | — | — | — | — | — | — |
| `Mysql` | `mysql://` URL | — | — | custom SQL | yes | — | — |
| `Redis` | `redis://` URL | — | — | Redis command | yes | yes | — |
| `Postgres` | `postgres://` URL | — | — | custom SQL | yes | — | — |

`follow_redirects` applies to HTTP and GraphQL (default `true`).

`ip_family` is `Ipv4`, `Ipv6`, or `Any` (default). Heartbeat monitors do not use outbound probes.

## HTTP and GraphQL

```terraform
resource "nominal_monitor" "api" {
  name   = "API health"
  type   = "Http"
  target = "https://example.com/health"
  method = "GET"

  request_headers {
    key   = "Authorization"
    value = "Bearer ${var.probe_token}"
  }

  conditions = [
    "[STATUS] >= 200",
    "[STATUS] <= 299",
  ]
}

resource "nominal_monitor" "graphql" {
  name         = "Admin GraphQL"
  type         = "GraphQL"
  target       = "https://example.com/graphql"
  request_body = "{ __typename }"
}
```

GraphQL monitors wrap `request_body` as a GraphQL query and default `method` to `POST`.

## DNS

`target` is the resolver. `dns_query_name` is the name to resolve. `dns_query_type` is `A`, `AAAA`, `CNAME`, `MX`, `NS`, `PTR`, `SRV`, or `TXT`.

```terraform
resource "nominal_monitor" "resolver" {
  name           = "example.com A"
  type           = "Dns"
  target         = "1.1.1.1"
  dns_query_name = "example.com"
  dns_query_type = "A"
  conditions     = ["[DNS_RCODE] == NOERROR"]
}
```

DNS monitors do not support `[DOMAIN_EXPIRATION]`.

## Heartbeat

Heartbeat monitors wait for your job to ping Nominal. After apply, use the computed URLs:

- `heartbeat_url` — finish signal (same as `heartbeat_finish_url`)
- `heartbeat_start_url` — job started
- `heartbeat_finish_url` — job succeeded
- `heartbeat_error_url` — job failed

`interval_seconds` is how often a finish signal is expected. After `/start`, the job must finish within that interval or the monitor is treated as hung.

Nominal clears conditions and probe attachments on heartbeat monitors. `heartbeat_token` is generated by the API and is sensitive.

```terraform
resource "nominal_monitor" "backup" {
  name   = "Nightly backup"
  type   = "Heartbeat"
  target = "backup-job"
}
```

## Databases

Targets must be connection URLs:

| Type | Schemes | Example |
| --- | --- | --- |
| `Mysql` | `mysql`, `mysqls`, `mariadb`, `mariadbs` | `mysql://user:pass@db.example.com:3306/app` |
| `Redis` | `redis`, `rediss` | `redis://:pass@cache.example.com:6379/0` |
| `Postgres` | `postgres`, `postgresql`, `pgsql`, `postgresqls` | `postgres://user:pass@db.example.com:5432/app` |

Default ports: MySQL 3306, Redis 6379 (`rediss` 6380), PostgreSQL 5432. TLS schemes and `sslmode` / `ssl-mode` query parameters control TLS. `verify_tls` maps onto verify-full vs require when no explicit sslmode is set.

`request_body` is optional custom SQL (MySQL/Postgres) or a Redis command.

## Proxies

`proxy_url` is sensitive. It applies to `Http`, `GraphQL`, `Tcp`, `Tls`, `WebSocket`, and `Redis`. HTTP and SOCKS URLs are accepted, for example `socks5h://127.0.0.1:1080`.

## Defaults when conditions are omitted

Nominal fills type defaults if you omit `conditions`. See [Conditions](conditions.md).
